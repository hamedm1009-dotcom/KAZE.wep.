# قائمة اختبار المرحلة الثالثة

## تحقق ساكن محلي
- [ ] ملفات JavaScript تمر بفحص الصياغة (`node --check`).
- [ ] ملفات ترجمة JSON صالحة.
- [ ] ملف migration ينفذ ويزرع الأقسام الستة في SQLite/D1.
- [ ] لا توجد مفاتيح خدمة أو بيانات اعتماد فعلية في المستودع.

## بعد ربط Firebase وCloudflare
- [ ] `/api/health` يعيد HTTP 200 وقاعدة البيانات `connected`.
- [ ] `/api/categories` يعيد الأقسام الستة.
- [ ] `/api/me` بدون Bearer token يعيد 401.
- [ ] `/api/admin/check` بدون Bearer token يعيد 401.
- [ ] حساب مسجل يستطيع قراءة ملفه الشخصي فقط.
- [ ] بيانات UID المرسلة من المتصفح لا تغير هوية صاحب الملف؛ الخادم يستخدم `sub` من ID token المُتحقق منه.
- [ ] مستخدم عادي يعيد 403 من `/api/admin/check`.
- [ ] UID المدير المضبوط فقط يحصل على 200 من `/api/admin/check`.
- [ ] `/api/admin/profiles` محمي بنفس صلاحية المدير.
- [ ] رمز من مشروع Firebase مختلف أو منتهي الصلاحية يُرفض.
- [ ] إنشاء الحساب واستعادة كلمة المرور ودخول Google تعمل بعد تفعيل طرق الدخول وإضافة الدومين المصرح.

## حدود معروفة
- هذه المرحلة لا تشمل عمليات الطلبات أو المخزون الفعلي؛ تأتي في المراحل التالية.
- لا تنشر المتجر تجاريًا قبل تمرير جميع الاختبارات ومراجعة سياسات الخصوصية والنسخ الاحتياطي.
