# قائمة أمان KAZE قبل الإنتاج

هذه القائمة تحدد اختبارات لازمة؛ وجود الكود وحده لا يعني اجتياز الاختبارات.

- [ ] Firebase ID token يُتحقق منه تشفيريًا مع issuer وaudience ووقت الانتهاء.
- [ ] كل API حساس يرفض الطلبات دون Bearer token صالح.
- [ ] العميل يقرأ ملفه الشخصي فقط؛ UID مأخوذ من الرمز وليس من body الطلب.
- [ ] العميل لا يستطيع قراءة قائمة ملفات العملاء من `/api/admin/profiles`.
- [ ] UID المدير مضبوط من Secret باسم `ADMIN_UID` وليس من كود الواجهة.
- [ ] حساب عادي يحصل على 403 من `/api/admin/check`، وحساب المدير المضبوط فقط يحصل على 200.
- [ ] أسعار المنتجات والمخزون والخصومات في المراحل القادمة تُحسب وتُتحقق على الخادم، لا من بيانات المتصفح.
- [ ] أوامر SQL تستخدم prepared statements وقيمها مربوطة، ولا تُبنى من مدخلات المستخدم.
- [ ] لا توجد Service Account keys أو أسرار أو كلمات مرور في GitHub.
- [ ] يتم اختبار المعدلات والحدود والنسخ الاحتياطي وسياسة حذف البيانات قبل الإطلاق التجاري.

الحالة الحالية: تم فحص صياغة الملفات وترحيل SQL محليًا. لا تزال اختبارات Firebase وCloudflare الحقيقية معلقة حتى إدخال إعدادات الحسابات وتشغيل اختبار المتصفح المبين في `PHASE-3-SETUP.md`.
